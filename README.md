# Ali Trading Bot

Freqtrade-Bot mit der Strategie **MomentumBreakout**, gesteuert über Telegram.

**Installation auf dem Server (ein Befehl):**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Erste-Hilfe-Hero/ali-trading-bot/main/install.sh)
```

Startet im **Testmodus** (kein echtes Geld). Alle Details in [ANLEITUNG.md](ANLEITUNG.md).

> Keine API-Keys oder Tokens in dieses Repo hochladen. Die gehören nur in die `.env` auf dem Server.
